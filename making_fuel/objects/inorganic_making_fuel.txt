=================================================================
MAKING FUEL: FUEL MINERALS
=================================================================
These live in raws rather than being injected because ENVIRONMENT
tags are read during worldgen, when the stone layers are built.
Nothing injected at runtime can place a mineral in the ground, so
this is the one part of the module that cannot be injected.

Everything else Making Fuel adds stays injected.

-----------------------------------------------------------------
IDS: THE MKGFUEL_ PREFIX
-----------------------------------------------------------------
Every inorganic this file ADDS carries MKGFUEL_, so it cannot
collide with another raw mod's anthracite or bitumen: two mods
declaring the same INORGANIC id leave only one of them standing.

Not MAKING_FUEL_. That is the module's prefix, and RM's module
engine removes every inorganic carrying it from memory at each data
cycle, which is how injected materials leave before a save. A stone
the world was built from must never be swept, so these carry a
prefix RM does not look for.

Reaction classes keep the plain name: ANTHRACITE, BITUMEN and the
rest name the material indirectly, and another mod's material can
join a chain by carrying one.

PEAT keeps its vanilla id, because it replaces vanilla peat.

-----------------------------------------------------------------
HOW ENVIRONMENT TAGS WORK
-----------------------------------------------------------------
ENVIRONMENT:<rock class>:<inclusion>:<probability>
    Places the mineral in a whole class of stone.
    Rock classes: SEDIMENTARY, IGNEOUS_EXTRUSIVE, IGNEOUS_INTRUSIVE,
                  METAMORPHIC, SOIL, SOIL_OCEAN, SOIL_SAND,
                  ALLUVIAL, ALL_STONE

ENVIRONMENT_SPEC:<specific stone>:<inclusion>:<probability>
    Places it inside one named stone only. Vanilla graphite uses
    four of these to sit in gneiss, quartzite, marble and schist.

Inclusion types:
    VEIN            long snaking seams. Vanilla lignite uses this.
    CLUSTER         irregular blobs, the largest deposits.
    CLUSTER_SMALL   3 to 6 tiles.
    CLUSTER_ONE     a single tile. Use for rare, valuable things.

Probability is 1 to 100 and is relative, not absolute. It weights
this mineral against every other mineral competing for the same
placement, so 100 does not mean "always".
=================================================================

ANTHRACITE
The coal that does not need you. Bituminous is metamorphosed
lignite; anthracite is metamorphosed bituminous, driven so far
that almost nothing volatile is left. That single fact decides
everything about how it behaves here.

It will NOT COKE. Coking works because volatile matter softens
the coal and fuses it into a cake, and anthracite has too little
left to soften. Historically this is exactly why anthracite was
burned raw in stoves and blast furnaces while bituminous went to
the coke oven first. So the retort pays it almost no liquid and
nearly all solid, which is the inverse of lignite.

METAMORPHIC, not sedimentary. Both vanilla coals sit in
sedimentary veins; anthracite forms where sedimentary coal has
been cooked by pressure, so it belongs in the metamorphic layers
and nowhere else. That also keeps it off the same embarks as the
other two more often than not.
=================================================================

BITUMEN
Natural solid bitumen, the gilsonite of the real world. Fills
fractures in oil bearing sediment. Yields pitch directly with no
distilation, which makes it the shortcut into the binder economy
for a fort that finds it.
=================================================================
[INORGANIC:MKGFUEL_BITUMEN]
[USE_MATERIAL_TEMPLATE:STONE_TEMPLATE]
[STATE_NAME_ADJ:ALL_SOLID:bitumen][DISPLAY_COLOR:0:7:1][TILE:'%']

the three bitumen bound briquette presses ask for as binder, so

TAR SAND
Bituminous sand. A sand soil layer, not a mineral inclusion, so it
is gathered with the native Collect Sand job rather than mined.
The collected bag is the wash reagent: washing separates bitumen
from ordinary sand, giving two useful outputs from one gather.

SOIL_SAND is the flag the Collect Sand job reads, and it only
works on a layer material. That is why this entry uses
SOIL_TEMPLATE and carries no ENVIRONMENT tags at all. Layer
placement is assigned by biome, not by inclusion rules.

Peat goes the opposite way for the opposite reason. There is no
collect job for peat, so peat had to stop being a layer and
become a diggable inclusion. Sand already has a collect job, so
tar sand stays a layer.

AQUIFER is deliberately absent. Every vanilla sand carries it,
but bitumen cemented sand is not permeable, and an aquifer layer
is miserable to dig through.
=================================================================
